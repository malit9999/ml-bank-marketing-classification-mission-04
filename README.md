# Bank Marketing Classification

> **Bootcamp Mission 04** | Machine Learning Classification

## 미션 소개
은행 마케팅 데이터를 활용해 고객의 캠페인 응답 여부를 분류하는 머신러닝 미션입니다. 범주형·수치형 변수를 전처리하고, 분류 문제의 평가 관점을 실습합니다.

## 구현 목표
- 목표 변수와 입력 변수의 관계를 분석한다.
- 분류 모델에 맞는 데이터 전처리 과정을 구성한다.
- 분류 결과를 적절한 지표로 평가한다.

## 주요 구현 내용
- 은행 마케팅 데이터 탐색
- 범주형 데이터 전처리
- 고객 응답 여부 분류와 결과 평가

## 사용 기술
- Python
- pandas
- scikit-learn
- Jupyter Notebook

## 실행 방법
```bash
pip install -r requirements.txt
jupyter notebook notebooks/mission04.ipynb
```
