# Bootcamp Mission 04 - 은행 마케팅 데이터 분류

## 1. 개요
포르투갈 은행 마케팅 데이터를 활용해 정기 예금 가입 가능성을 예측한 미션입니다.

## 2. 목표
고객 특성과 캠페인 정보를 바탕으로 예금 가입 여부를 분류하고, 마케팅 전략에 필요한 인사이트를 도출하는 것을 목표로 했습니다.

## 3. 사용 기술
- Python
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn
- imbalanced-learn
- xgboost
- lightgbm
- catboost

## 4. 주요 기능
- 은행 마케팅 데이터 EDA
- 분류 모델 학습
- 앙상블 모델 비교
- 불균형 데이터 처리 실험

## 5. 실행 방법
```bash
pip install -r requirements.txt
jupyter notebook notebooks/mission04.ipynb
```

## 6. 주요 파일
- `notebooks/mission04.ipynb`

## 7. 폴더 구조
```text
bootcamp-mission-04
  .gitignore
  notebooks/
    mission04.ipynb
  README.md
  requirements.txt
```

## 8. 학습 내용
분류 문제에서 모델 비교, 불균형 데이터 처리, 평가 지표 해석 방법을 학습했습니다.

## 9. 트러블슈팅
미션을 진행하며 발생한 오류와 해결 과정은 노트북 또는 보고서에 정리했습니다.

## 10. 결과 화면
결과 이미지는 노트북 출력, 보고서 또는 `images/` 폴더에서 확인할 수 있습니다.

## 11. 공개 전 확인 사항
- 제출 노트북만 포함했으며, 원본 데이터와 모델 파일은 공개 범위 확인 전 포함하지 않았습니다.
